# NeoVim custome configs

1. Install the NeoVim https://neovim.io/doc/install/
3. Install `gcc ripgrep` through package manager
4. Install [`luarock`](https://github.com/luarocks/luarocks/blob/main/docs/installation_instructions_for_unix.md)
4. Install clipboard provider for copy-pasting outside of a terminal
   - `pbcopy` for macOS
   - `xsel` for Linux
5. Clone the configuration `git clone https://github.com/hicugi/neovim-config.git ~/.config/nvim`
6. Use `:checkhealth`
